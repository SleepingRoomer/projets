# Les projets

La page qui présente les projets de trois collectifs, et permet de proposer son aide :

- **Sleeping Room** (pédagogie médicale) : Semiological, Physiopath, Methodocs, Quelle spé est faite pour moi ?, Anecdocs.
- **Soigner ou Saigner** (inégalités de soins) : Se soigner en France, Malades, Décoloniser la médecine.
- **Al Maydan** (culture) : Al Maktaba, Sullam, Un Ftor pour tous.

Tout tient dans `index.html`. Pour ajouter ou modifier un projet, modifiez le tableau `P` dans le script en bas du fichier ; pour l'adresse de contact d'un collectif, le champ `contact` du tableau `COLL`.

Site : https://sleepingroomer.github.io/projets/
